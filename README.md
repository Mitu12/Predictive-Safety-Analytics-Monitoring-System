# 📊 Predictive Safety Analytics & Monitoring System

## 📌 Overview

This project focuses on building an end-to-end **data analytics and business intelligence solution** to monitor safety performance and predict low-quality safety reports.

## 🎯 Objectives

* Analyze ISP (Industrial Safety Pause) data
* Identify trends in safety quality
* Detect root causes of low-quality reports
* Predict high-risk safety issues

## 🛠️ Tools & Technologies

* Power BI (Dashboard)
* Python (Modeling)
* Excel (Data Processing)
* DAX (Measures)

## 📊 Dashboard Pages

* Overview Dashboard
* Quality Analysis
* Root Cause Analysis
* Prediction Insights
  
## 📈 Key Insights

* Identified departments with highest low-quality reports
* Analyzed root causes of safety issues
* Built predictive model to detect high-risk reports
* Enabled data-driven safety decision-making

## 🚀 Project Highlights

* End-to-end data pipeline
* Interactive Power BI dashboards
* Predictive analytics integration
* Real-world business use case
